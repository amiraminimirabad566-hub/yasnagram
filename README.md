# یسناگرام — نسخه اولیه

این بسته یک نمونه اولیه فرانت‌اند قابل انتشار روی GitHub Pages است.

## انتشار
1. فایل‌های این پوشه را در ریشه مخزن GitHub با نام `yasnagram` بارگذاری کنید.
2. در GitHub وارد Settings → Pages شوید.
3. در بخش Build and deployment گزینه Deploy from a branch را انتخاب کنید.
4. Branch را روی `main` و پوشه را روی `/ (root)` بگذارید و Save کنید.
5. پس از چند دقیقه آدرس `https://USERNAME.github.io/yasnagram/` در دسترس می‌شود.

## وضعیت امکانات
- نمایش فید نمونه و پست محلی در مرورگر: فعال
- لایک نمایشی: فعال
- ورود/ثبت‌نام واقعی، ذخیره آنلاین، پیام خصوصی، مدیریت کاربران: هنوز فعال نیستند.
- این قابلیت‌ها به سرویس بک‌اند و پایگاه داده امن (مثلاً Supabase) نیاز دارند؛ GitHub Pages به‌تنهایی سرور برنامه نیست.
- فیلتر واژه‌های نمونه صرفاً یک کنترل ابتدایی است و تضمین تشخیص یا جلوگیری کامل از محتوای نامناسب نیست.

## امنیت
هرگز کلید خصوصی یا رمز سرویس را در فایل‌های عمومی GitHub قرار ندهید. برای اجرای عمومی باید احراز هویت، گزارش محتوا، محدودسازی سوءاستفاده و نظارت سمت سرور پیاده‌سازی شود.
